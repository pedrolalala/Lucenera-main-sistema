# Contexto Operacional

Esta pasta guarda as instrucoes de trabalho que mantem o repositorio central e os repositorios dos sistemas alinhados.

## Arquivos

- `FLUXO_DE_TRABALHO.md`: como iniciar, implementar, testar, documentar e commitar mudancas.
- `COMO_CRIAR_SPEC.md`: regra para criar ou atualizar SPEC antes de mexer em codigo ou banco.
- `SUBMODULES.md`: como registrar, clonar e atualizar os repositorios dos sistemas dentro de `04-Sistemas/`.
- `INVENTARIO_REPOSITORIOS.md`: mapa dos sistemas, repositorios GitHub, pastas locais e situacao de versionamento.
- `AGENTS.md`: instrucao especifica desta pasta.

## Quando atualizar

Atualize esta pasta quando mudar o processo de trabalho, a lista de repositorios, a regra de SPEC, o fluxo de commit ou a forma como o time usa a memoria compartilhada.
