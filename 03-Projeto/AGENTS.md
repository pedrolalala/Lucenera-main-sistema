# Instrucao da Pasta 03-Projeto

Esta pasta concentra relatorios finais, escopos, planos de acao e SPECs.

## Regras

- SPEC e a unidade principal para mudanca implementavel.
- Escopo explica responsabilidade de sistema; SPEC explica uma mudanca concreta.
- Relatorio final consolida entendimento para cliente e desenvolvedor.
- Atualizar `00_INDICE.md` quando adicionar documento estrutural novo.

## SPECs

Criar ou atualizar SPEC quando a mudanca envolver:

- codigo de sistema;
- banco, migration, trigger, funcao, view, storage ou RLS;
- integracao;
- permissao;
- relatorio;
- mudanca de fluxo operacional;
- mais de um sistema.

Usar `Planos de Ação/SPECs/_TEMPLATE_SPEC.md` e seguir `../00-Contexto/COMO_CRIAR_SPEC.md`.
