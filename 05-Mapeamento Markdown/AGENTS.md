# Instrucao da Pasta 05-Mapeamento Markdown

Esta pasta guarda a transcricao e reorganizacao em Markdown do board Miro "fluxograma Lucenera", separado por area/responsavel.

## Regras

- Texto deve permanecer fiel ao board, incluindo erros de digitacao originais do board; anotar ambiguidade em nota no proprio arquivo.
- `00_indice_e_notas_de_leitura.md` e o indice: atualizar sempre que um arquivo for adicionado, renomeado ou remapeado.
- Este conteudo e evidencia de processo (fonte: Miro), nao decisao final de sistema.
- `99_fluxo_total_do_escritorio.md` concentra a visao de alto nivel; mudar isso so quando o board mudar.

## Antes de usar este mapeamento para implementar algo

Verificar se ja existe decisao consolidada mais recente em:

1. `../02-Reunioes/00_FLUXOS_CONSOLIDADOS.md`
2. `../03-Projeto/Escopos/`
3. `../03-Projeto/Planos de Ação/SPECs/`
4. `../supabase/docs/`
